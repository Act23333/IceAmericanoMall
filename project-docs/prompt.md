你需求其实不是普通“做一个商城首页”，而是想做一个**具有品牌感的沉浸式作品展示 + 商城产品体验**。

你不要直接生成页面，而是先生成：

1. **视觉世界观**

2. **交互原则**

3. **页面信息架构**

4. **性能约束**

5. **开发任务拆解**

否则 AI 很容易做成“炫技网页”，动画很多但是卡顿、转化差。

下面给你一套可以直接给 Claude / Cursor / ChatGPT Code 用的完整提示词。

---

```

React 19
TypeScript
Tailwind CSS
Shadcn/ui
TanStack Query
Zustand

目标：
不是简单商城，而是一个具有品牌世界观的高端电商体验。

要求：
同时满足：

1. 高级视觉设计
2. 简洁
3. 极佳用户体验
4. 高并发访问性能
```

---

另外你后续不要用“京东首页复刻思路”，而是：

**首页 = 品牌体验**

**商城 = 转化效率**

这是 Apple、Nike、Tesla 这类品牌网站和传统电商最大的区别。

IceMall 这种项目，用这个方向会比单纯堆商品卡片高级很多。
