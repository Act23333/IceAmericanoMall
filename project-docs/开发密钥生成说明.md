# 开发环境 JWT 签名密钥生成说明

## 背景

V2.5 起，Keystore（`.jks`/`.p12`）已从 Git 移除（安全约束：`12-Security-Model §5.2`），`.gitignore` 排除所有 `*.jks` `*.p12`。每个开发者需在本地生成自己的 dev keystore。

## 生成命令

```bash
cd Implementation/back-end/authorization-service/src/main/resources/keystore

keytool -genkeypair \
  -alias dev-jwt-rsa \
  -keyalg RSA -keysize 2048 \
  -keystore dev.p12 \
  -storepass devpassDev1 \
  -keypass devpassDev1 \
  -dname "CN=IceAmericanoMall Dev, OU=Dev, O=IcedMall, L=SZ, ST=GD, C=CN" \
  -validity 3650
```

生成后确认文件存在：

```bash
ls -l dev.p12
```

无需提交 Git（`.gitignore` 已排除）。

## 配置

`application.yml` 已配置 dev 默认值：

- `key-store-path: keystore/dev.p12`
- `key-password: ${JWT_KEYSTORE_PASSWORD:devpassDev1}`
- `keystore-password: ${JWT_KEYSTORE_PASSWORD:devpassDev1}`
- `key-alias: dev-jwt-rsa`

本地开发无需额外配置（密码/路径有默认值）。**生产环境须通过环境变量注入**：`JWT_KEYSTORE_PATH`、`JWT_KEYSTORE_PASSWORD`（`JwkSourceConfig` 自动从 `System.getenv` 读取）。

## 验证

```bash
# 启动 authorization-service
mvn -f Implementation/back-end/authorization-service -DskipTests spring-boot:run
# 验证 JWKS 端点返回公钥
curl http://localhost:9000/oauth2/jwks
```

应返回包含 `keys` 数组的 JSON，key 带 `use=sig`、`alg=RS256`、`kty=RSA`。
