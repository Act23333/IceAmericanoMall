# 服务调用工具

## 一、整体分两大阵营

### 1）HTTP REST 调用（通用、简单、前后端通用，Spring 微服务主流）

基于 **HTTP + JSON**，既能**微服务内部调用**，也能**调用第三方外网接口**，调试友好。

表格

|工具|定位 / 特点|性能|适用场景|
|---|---|---|---|
|**RestClient**|Spring 官方新一代同步客户端，**RestTemplate 替代品**|良好|90% 常规业务、微服务互调、第三方接口，**你的项目首选**|
|**WebClient**|响应式非阻塞异步客户端|优秀|高并发、批量请求、流式接口|
|**OpenFeign**|声明式调用，Spring Cloud 传统标配|一般|快速开发、老微服务项目|
|**@HttpExchange**|Spring 官方声明式方案，**Feign 替代品**|优秀|想优雅写接口式调用，无反射、性能更强|
|**RestTemplate**|老牌同步客户端|一般|已废弃，仅老项目维护|
|**Micronaut Client**|极致性能声明式客户端|顶级|仅 Micronaut 框架，**Spring 项目不兼容**|

---

### 2）RPC 高性能调用（速度快、二进制、内网专用）

基于 **HTTP/2 或 TCP + 二进制序列化**，性能远超 HTTP，**一般不用于第三方接口**。

表格

|工具|定位 / 特点|性能|适用场景|
|---|---|---|---|
|**gRPC**|跨语言、HTTP/2、Protobuf|顶级|高并发、微服务内网高性能调用、跨语言|
|**Dubbo**|Java 生态高性能 RPC|顶级|纯 Java 微服务、大规模集群、强服务治理|

---

# 二、3 条核心铁律

1. **所有 HTTP 类客户端都能调用第三方接口**（写完整网址即可），RPC 一般不用于外网第三方。
2. **微服务内部调用**：HTTP 用服务名 lb://，RPC 用注册中心（Nacos / 注册中心）自动发现。
3. **Spring Boot 3 最佳路线**：
    
    - 普通调用 → **RestClient**
    - 声明式优雅调用 → **@HttpExchange**
    - 高并发异步 → **WebClient**
    - 极致性能内网调用 → **gRPC**
    

---

# 三、一句话最终总结

- **日常微服务 + 第三方接口**：用 **RestClient** 最简单、最稳、最适配你的项目。
- **想写接口式声明调用**：用 **@HttpExchange** 替代 OpenFeign。
- **追求极致性能内网调用**：上 **gRPC**。
- **Micronaut/Dubbo** 非特殊场景不必引入，增加复杂度。
## 第三方通用 HTTP 客户端（底层工具）

这些是**基础 HTTP 工具**，RestClient/WebClient/OpenFeign 底层都可以用它们提升性能：

### ① **OkHttp**（Square 出品，业界最强）

- 高性能、连接池复用、HTTP/2 支持
- 很多框架（Retrofit、Feign）默认底层就是它

### ② **Apache HttpClient**（老牌稳定）

- 企业级老牌工具，功能极全
- 兼容性好，老系统常用
