创建 `user-service` 微服务的过程需要遵循清晰的**分层架构**，从数据模型开始，逐步向上构建业务逻辑和接口。下面以 MyBatis-Plus 为例，给出推荐的顺序和每个步骤的具体内容。

---

## 一、整体步骤概览

1. **数据库表设计与创建**（依据领域模型）
2. **创建实体类（Entity）**（与表映射）
3. **创建数据访问层（Mapper）**（继承 MyBatis-Plus 的 `BaseMapper`）
4. **创建服务层（Service）接口与实现**（业务逻辑）
5. **创建控制器层（Controller）**（处理 HTTP 请求）
6. **定义 DTO / VO**（数据传输对象）
7. **配置与集成**（MyBatis-Plus、数据源等）

**原则**：从下往上，从数据模型开始，确保依赖关系清晰，便于单元测试和模块化。

---

## 二、详细步骤

### 1. 设计并创建数据库表
根据之前领域的用户实体（User），创建对应的数据库表 `user`（如果尚未创建）。表结构应包含字段：`id`（技术主键）、`user_id`（业务标识）、`username`、`phone`、`password`、`avatar`、`register_time`、`status`、`balance` 等，并添加索引。

```sql
CREATE TABLE `user` (
    `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
    `user_id` VARCHAR(32) NOT NULL UNIQUE,
    `username` VARCHAR(50) DEFAULT NULL,
    `phone` VARCHAR(20) NOT NULL UNIQUE,
    `password` VARCHAR(100) NOT NULL,
    `avatar` VARCHAR(255) DEFAULT NULL,
    `register_time` DATETIME NOT NULL,
    `status` TINYINT NOT NULL DEFAULT 1,
    `balance` INT NOT NULL DEFAULT 0,
    `create_time` DATETIME NOT NULL,
    `update_time` DATETIME NOT NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2. 创建实体类（Entity）
在 `user-service` 模块中创建 `entity` 包，添加 `UserEntity` 类。使用 MyBatis-Plus 注解映射表、主键、字段等。

```java
package org.nolazy.userservice.entity;

import com.baomidou.mybatisplus.annotation.*;
import lombok.Data;
import java.time.LocalDateTime;

@Data
@TableName("user")
public class UserEntity {
    @TableId(type = IdType.AUTO)
    private Long id;
    
    private String userId;
    private String username;
    private String phone;
    private String password;
    private String avatar;
    private LocalDateTime registerTime;
    private Integer status;
    private Integer balance;
    
    @TableField(fill = FieldFill.INSERT)
    private LocalDateTime createTime;
    
    @TableField(fill = FieldFill.INSERT_UPDATE)
    private LocalDateTime updateTime;
}
```

### 3. 创建 Mapper 接口
在 `mapper` 包中创建 `UserMapper` 接口，继承 MyBatis-Plus 的 `BaseMapper<UserEntity>`，无需编写 SQL（除非有复杂查询）。

```java
package org.nolazy.userservice.mapper;

import com.baomidou.mybatisplus.core.mapper.BaseMapper;
import org.apache.ibatis.annotations.Mapper;
import org.nolazy.userservice.entity.UserEntity;

@Mapper
public interface UserMapper extends BaseMapper<UserEntity> {
}
```

### 4. 创建 Service 层
先定义接口，再实现。Service 层封装业务逻辑，如注册、登录、查询用户等。

**接口**：
```java
package org.nolazy.userservice.service;

import org.nolazy.userservice.dto.UserRegisterDTO;
import org.nolazy.userservice.dto.UserLoginDTO;
import org.nolazy.userservice.dto.UserDTO;
import org.nolazy.common.domain.PageRequest;
import org.nolazy.common.domain.PageDTO;

public interface UserService {
    UserDTO register(UserRegisterDTO dto);
    String login(UserLoginDTO dto);
    UserDTO getUserById(Long id);
    PageDTO<UserDTO> pageUsers(PageRequest pageRequest);
}
```

**实现类**：
```java
package org.nolazy.userservice.service.impl;

import lombok.RequiredArgsConstructor;
import org.nolazy.userservice.dto.UserRegisterDTO;
import org.nolazy.userservice.dto.UserLoginDTO;
import org.nolazy.userservice.dto.UserDTO;
import org.nolazy.userservice.entity.UserEntity;
import org.nolazy.userservice.mapper.UserMapper;
import org.nolazy.userservice.service.UserService;
import org.nolazy.common.exception.BizException;
import org.nolazy.common.utils.BeanUtils;
import org.springframework.stereotype.Service;
import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.baomidou.mybatisplus.extension.plugins.pagination.Page;

@Service
@RequiredArgsConstructor
public class UserServiceImpl implements UserService {
    private final UserMapper userMapper;

    @Override
    public UserDTO register(UserRegisterDTO dto) {
        // 1. 检查手机号是否已存在
        LambdaQueryWrapper<UserEntity> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(UserEntity::getPhone, dto.getPhone());
        if (userMapper.selectCount(wrapper) > 0) {
            throw new BizException("手机号已注册");
        }
        // 2. 创建用户实体
        UserEntity entity = BeanUtils.copyBean(dto, UserEntity.class);
        entity.setUserId(generateUserId()); // 生成业务ID
        entity.setRegisterTime(LocalDateTime.now());
        entity.setStatus(1);
        entity.setBalance(0);
        // 3. 加密密码
        entity.setPassword(passwordEncoder.encode(dto.getPassword()));
        // 4. 保存
        userMapper.insert(entity);
        // 5. 返回DTO
        return BeanUtils.copyBean(entity, UserDTO.class);
    }

    // ... 其他方法
}
```

### 5. 创建 DTO / VO

### 6. 创建 Controller 层
在 `controller` 包中编写 REST 接口，处理请求，调用 Service，并返回统一响应 `Result`。

```java
package org.nolazy.userservice.controller;

import lombok.RequiredArgsConstructor;
import org.nolazy.userservice.dto.UserRegisterDTO;
import org.nolazy.userservice.dto.UserLoginDTO;
import org.nolazy.userservice.dto.UserDTO;
import org.nolazy.userservice.service.UserService;
import org.nolazy.common.domain.PageRequest;
import org.nolazy.common.domain.PageDTO;
import org.nolazy.common.result.Result;
import org.springframework.validation.annotation.Validated;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/user")
@RequiredArgsConstructor
public class UserController {
    private final UserService userService;

    @PostMapping("/register")
    public Result<UserDTO> register(@Validated @RequestBody UserRegisterDTO dto) {
        UserDTO user = userService.register(dto);
        return Result.success(user);
    }

    @PostMapping("/login")
    public Result<String> login(@Validated @RequestBody UserLoginDTO dto) {
        String token = userService.login(dto);
        return Result.success(token);
    }

    @GetMapping("/{id}")
    public Result<UserDTO> getUser(@PathVariable Long id) {
        UserDTO user = userService.getUserById(id);
        return Result.success(user);
    }

    @GetMapping("/page")
    public Result<PageDTO<UserDTO>> pageUsers(PageRequest pageRequest) {
        PageDTO<UserDTO> page = userService.pageUsers(pageRequest);
        return Result.success(page);
    }
}
```

## 三、为什么这样安排？

- **从下往上**：先定义实体和 Mapper，让 Service 和 Controller 可以依赖它们，避免循环依赖。
- **分层清晰**：Controller 只处理请求和响应，Service 封装业务逻辑，Mapper 只负责数据访问。每层职责单一，易于测试和维护。
- **依赖倒置**：Service 依赖 Mapper（接口），Controller 依赖 Service（接口），方便解耦和单元测试。
- **使用 DTO**：避免将 Entity 暴露给前端，保护敏感字段（如密码），也便于字段裁剪和格式转换。
- **统一响应**：所有 Controller 返回 `Result<T>`，确保 API 风格一致。

## 四、其他注意事项

- 密码必须加密存储，不能明文。
- 注册时需校验验证码，并处理幂等性（防止重复提交）。
- 分页查询使用 MyBatis-Plus 的 `Page` 和 `PageDTO` 封装。
- 使用 Lombok 简化代码，但注意与 MapStruct 的注解处理器顺序（Lombok 在前，MapStruct 在后）。

按照这个顺序和分层，你可以稳健地构建 `user-service` 微服务。其他微服务（如 `product-service`、`order-service`）可参照类似模式。
