### 1. 发送验证码

- **URL**：`POST /api/user/captcha`
    
- **请求体**：`{ "phone": "13800138000" }`
    
- **响应**：`{ "code": 200, "message": "发送成功" }`
    
- **说明**：生成验证码并存入 Redis，调用短信服务发送。
    

### 2. 注册

- **URL**：`POST /api/user/register`
    
- **请求体**：`{ "phone": "13800138000", "captcha": "123456", "password": "123456", "requestId": "uuid" }`（requestId 用于幂等）
    
- **响应**：`{ "code": 200, "data": { "token": "jwt_token", "userId": 123 } }`
    
- **说明**：校验验证码、加密密码、创建用户、生成 JWT。
    

### 3. 登录

- **URL**：`POST /api/user/login`
    
- **请求体**：`{ "phone": "13800138000", "password": "123456", "captcha": "123456" }`（密码登录也可省略验证码，根据安全策略定）
    
- **响应**：同上。
    

### 4. 获取用户信息

- **URL**：`GET /api/user/info`
    
- **请求头**：`Authorization: Bearer jwt_token`
    
- **响应**：`{ "code": 200, "data": { "userId": 123, "nickname": "张三", "avatar": "...", "balance": 1000 } }`
    

### 5. 管理员登录（可单独）

- **URL**：`POST /api/admin/login`
    
- **请求体**：`{ "username": "admin", "password": "123456" }`
    
- **响应**：`{ "code": 200, "data": { "token": "admin_jwt" } }`
